# AVA — check-in game

Одностраничная мини-игра авиакомпании **AVA** с девизом **AVA MARIA, AVA VICTORIA**. Три блока регистрации проверяют одну заданную бронь и выдают игровой посадочный талон. React, TypeScript, Vite, Motion и React Three Fiber. Все работает в браузере, без backend и сохранения введенных данных. Интерфейс использует относительные размеры, чтобы помещаться в экран без прокрутки; за 3D-глобусом размещена фигура молящегося человека. На глобусе самолёт проходит по декоративному маршруту LED → Токио, Ханэда (HND), а нижняя полоса показывает следующий рейс.

После успешной регистрации открывается сцена **security check**: красная и синяя сирены, разрыв билета из `public/ticket.jpg` и приближение к полю **GATE** с выходом, заданным в `FLIGHT.gate`. Анимации завершаются автоматически; при reduced motion сразу показывается статичный результат. Сцену можно повторить с экрана посадочного талона.

Кнопка скачивания после security check сначала открывает анимированную шуточную модалку с `public/why.webp`. Можно закрыть её кнопкой «Ладно, понял» или выбрать «Всё равно скачать» для сохранения игрового талона в SVG.

При входе с телефона открывается обязательная модалка с мигалками и `public/security.jpg`: проверку нужно проходить на компьютере или ноутбуке. Закрыть её и продолжить регистрацию на телефоне нельзя; кнопка позволяет скопировать ссылку для открытия на компьютере. Поворот телефона и запрос desktop-версии сохраняют ограничение. На телефоне 3D-глобус не загружается. Уменьшение окна настольного браузера само по себе не блокирует игру.

## Запуск

Нужен Node.js 22.13+ из ветки 22, Node.js 24 или 26+.

```sh
npm install
npm run dev
```

```sh
npm run build   # production-сборка в dist/
npm run preview # локальный просмотр сборки
npm test        # проверка правил регистрации
npm run lint
```

Браузерные проверки используют установленный Google Chrome и сами запускают dev-сервер:

```sh
npm run test:e2e
```

Если Chrome не установлен, можно использовать Chromium от Playwright:

```sh
npx playwright install chromium
PLAYWRIGHT_CHROMIUM_CHANNEL=chromium npm run test:e2e
```

Тесты проверяют квитанцию, ошибки ввода, прохождение, скачивание талона, возврат к предыдущим шагам, последовательность security check, повтор сцены, обязательный переход с телефона на компьютер, копирование ссылки и reduced motion. Скриншоты на ширине 375, 768, 1440 и 1920 px сохраняются в `artifacts/`; отчеты об ошибках — в `test-results/`. Настройка браузера описана в [документации Playwright](https://playwright.dev/docs/browsers).

## Данные для прохождения

Единственная допустимая бронь задается константами в [src/domain/checkIn.ts](src/domain/checkIn.ts). Чтобы изменить сценарий, обновите значения там.

| Поле                        | Значение   |
| --------------------------- | ---------- |
| Фамилия                     | Васильев   |
| Имя                         | Александр  |
| Отчество                    | Олегович   |
| Дата рождения               | 1991-12-19 |
| Номер рейса                 | AVA 303    |
| Код брони                   | VB3393     |
| Дата вылета                 | 2026-10-24 |
| Последние 4 цифры документа | 8436       |

Регистр букв и лишние пробелы нормализуются; данные должны соответствовать одной и той же брони. После прохождения пользователь получает игровой посадочный талон. Константы доступны в клиентской сборке: это игровая проверка, а не настоящая аутентификация или регистрация на авиарейс.

## GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Отправьте проект и `package-lock.json` в ветку `main` либо вручную запустите **Deploy to GitHub Pages** на вкладке Actions.

[.github/workflows/deploy.yml](.github/workflows/deploy.yml) устанавливает зависимости через `npm ci`, собирает проект и публикует `dist/`. Путь ресурсов определяется автоматически: `/` для репозитория `OWNER.github.io` и `/REPOSITORY/` для обычного репозитория. При использовании собственного домена замените аргумент `--base` в шаге сборки на `/`.

Справка: [публикация Vite на GitHub Pages](https://vite.dev/guide/static-deploy.html#github-pages).
